# CoinQuest

CoinQuest is a gamified student budgeting application that helps students build better financial habits through quests, XP rewards, achievements, savings goals, and transaction tracking.

## Features

* User Profiles
* XP and Leveling System
* Quest Completion Rewards
* Achievement Badge System
* Savings Goals Dashboard
* Transaction Tracking
* Income and Expense Monitoring
* Quest Progress Tracking
* Achievement Unlock Tracking
